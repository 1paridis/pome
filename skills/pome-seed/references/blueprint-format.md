# blueprint.md 格式与结构门禁

## 标题层级

- 用 Markdown 多级标题表示树的层级：根为 `#`，第二层 `##`，以此类推，标题层级 = 树的深度。
- 节点标题只写功能名称，不添加数字、字母或点分序号前缀。

## 节点形态

- **根节点**：`#` 标题下依次写补充说明、范围。
- **分支节点**：只有标题，不写说明。
- **叶子节点**：标题下方使用「功能说明」小节，简洁说明该功能做什么。

## 完整示例

```markdown
# 需求标题

> 根节点需求的补充说明

**范围**

- 包含：……
- 不包含：……

## 子功能 A

**功能说明**

简洁说明该功能做什么。

## 功能分组

### 叶子功能 A

**功能说明**

简洁说明该功能做什么。

### 深层功能分组

#### 四层叶子功能

**功能说明**

简洁说明该功能做什么。
```

## 技术方案小节

阶段二为每个叶子补写，位于「功能说明」之后：

```markdown
### 用户登录

**功能说明**

支持邮箱 + 密码登录，失败提示具体原因。

**技术方案**

在 `auth/login.py` 新增 `login(email, password)`，调用既有的 `User.query_by_email` 校验密码哈希，成功则签发 JWT（复用 `utils/jwt.py`），失败返回对应错误码。注意密码比对须用常量时间比较，避免时序攻击。
```

## 自检清单（逐条核对）

- [ ] 标题层级 = 树的深度，无跳级、无加粗正文或列表伪造树节点
- [ ] 标题无序号前缀
- [ ] 叶子节点都有「功能说明」
- [ ] 分支节点无说明文字
- [ ] 同一父节点下子节点标题不重复
- [ ] 阶段二后每个叶子都有「技术方案」
