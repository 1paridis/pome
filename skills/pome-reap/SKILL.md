# pome-reap

收割归档。把 `.pome/nursery/` 中当前工作流的全部产物移动归档到 `.pome/archive/<任务简称>/`，为下一次工作流腾出干净的 nursery。本技能只确定归档目标并调用脚本完成移动，不修改、不删除任何文档内容。

## 输入

- `.pome/nursery/`：当前工作流的产物目录，通常含 `blueprint.md`、`test-case.md`、`tasks.md` 中的一种或多种。
- 任务简称：命名归档目录的短名称，来源优先级：

  1. 用户明确指定；
  2. 从 nursery 中设计文档的根标题推导（`blueprint.md` 或 `test-case.md` 的一级 `#` 标题），压缩成简洁可读的短名。

归档目录 `.pome/archive/` 下已存在的归档是受保护历史，只读，不得移动、覆盖、删除或改写。

## 归档前检查

执行归档前逐项检查，任一不满足则报告后暂停：

- `nursery` 存在且非空；为空或不存在时无可归档产物，停止且不创建空归档目录。
- 任务简称非空，且经脚本清洗后仍是有效目录名。
- 目标目录 `.pome/archive/<任务简称>/` 不存在或为空；已存在同名非空归档时，说明简称可能被占用，暂停请用户换一个简称或明确覆盖/合并。

## 归档规则

- 移动动作一律通过 `scripts/reap.py` 完成，不手写 `mv`、`cp`、`rm` 命令。
- 脚本移动 `nursery` 下的全部条目到归档目录；`nursery` 清空后保留目录本身，供下次工作流复用。
- 归档只做位置迁移，不改动文件内容与文件名。
- 不删除任何文件；归档后校验源已清空、目标包含全部原条目。

脚本用法（脚本位于本 skill 目录的 `scripts/` 下，路径按 skill 目录解析）：

```bash
python <skill-dir>/scripts/reap.py "<任务简称>"
```

可先以 `--dry-run` 预览将移动的条目，再实际执行。脚本默认读 `.pome/nursery`、写 `.pome/archive`；需要时可经 `--nursery`、`--archive-root` 覆盖。

## 产物结构

```text
.pome
├── archive
│   └── <任务简称>
│       ├── blueprint.md
│       ├── test-case.md
│       └── tasks.md
└── nursery            ← 归档后为空
```

## 执行流程

1. 定位 `.pome/nursery/`，列出其中的全部产物。
2. 确定任务简称：用户指定优先，否则从设计文档根标题推导；无法确定时向用户确认。
3. 执行归档前检查；不满足时报告并暂停，等待用户处理。
4. 调用脚本完成移动：`python <skill-dir>/scripts/reap.py "<任务简称>"`。
5. 校验：`nursery` 已清空，归档目录包含全部原条目，文件名与内容一致。
6. 报告归档路径与归档文件清单，并提醒用户归档目录为受保护历史。

## 自检

归档后逐项自检，任一不过则回退修正：

- 位置正确：全部产物已从 `nursery` 移到 `.pome/archive/<任务简称>/`，`nursery` 为空。
- 内容完整：文件名与内容一致，无丢失、无改动、无残留。
- 历史受保护：既有归档目录未被移动、覆盖、删除或改写。
